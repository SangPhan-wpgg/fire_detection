# Cấu hình thí nghiệm

Mỗi thí nghiệm mới nên sao chép một cấu hình model sang thư mục này và đổi
`experiment_id`. Không sửa cấu hình của một lần chạy đã dùng để báo cáo.

Tối thiểu phải lưu: phiên bản dữ liệu, model, seed, kích thước ảnh, batch,
optimizer, learning rate, checkpoint và môi trường thực thi.
