# Notebook

- `data/`: khám phá, tiền xử lý và tăng cường dữ liệu.
- `detection/`: thí nghiệm các mô hình phát hiện đối tượng.
- `segmentation/`: thí nghiệm phân đoạn vùng cháy.
- `analysis/`: so sánh mô hình và phân tích lỗi.

Notebook phục vụ khám phá và trình bày. Logic tái sử dụng nằm trong
`src/fire_detection/`; các tác vụ chạy lặp lại nằm trong `scripts/`.
